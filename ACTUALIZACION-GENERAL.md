# Aviso de actualización general

Enviar después de publicar la versión **0.62.0** del kit y la documentación de la web.

> Equipo: actualicen Softnexus Spec Driven a la versión 0.62.0 una sola vez por computador. En un único chat de Claude Code, peguen: «Actualiza el plugin Softnexus para mi usuario y, con el motor recién instalado, ejecuta `actualizar --general`; comprueba también las copias de proyecto e informa cualquier fallo». Al terminar, cierren todas las sesiones de Claude Code y vuelvan a abrirlo. No hay que repetirlo en cada chat.

Si la versión antigua no entiende esa instrucción, usar el arranque del [manual](https://sd.softnexus.io/doc.html?f=MANUAL-NINOS.md).
